# 学术报告样式

生成器默认使用白色纸面、墨色正文、深蓝标题（#19364D）和青绿强调（#007F7A）。层级、对齐和留白承担信息组织；避免加入装饰卡片、彩虹配色或不表达数值的图形。

- 标题应说清主题，副标题交代范围/材料性质，作者与日期放 meta。已有编号的章节会保留原文，目录不会重复追加编号。
- 纯文字、列表、单图、单表、图表页和混排均可按内容独立使用，不设视觉数量或混排比例要求。需要短解释配图片时可使用 1:1.3 至 1:1.5 的双列，让主要视觉获得空间；长正文、多系列趋势或宽表用全宽，不要为了并排把图中文字压小。手机和打印按左→右阅读。
- 图表先确定比较口径，再选形式。系列顺序使用青绿、蓝、赭黄、紫等克制配色，与 Word/PPT 保持前两系列的同色含义。轴文字、单位与图例清晰，折线同时用颜色和线型区分，图例保持同一线型及点标记，便于黑白打印。自动轴刻度不改变输入数值精度。
- 表格使用顶部、表头分隔、底部的主横线及轻量行分隔，不使用竖线网格。单位尽量放在列名；数值列自动右对齐，缺测文本保持在同列。需要保留 8.20 等报告精度时在 table 单元格传字符串，chart 仍传数字。
- 图注在图下左对齐，先说图表达什么，再以次要字号给出来源与引用。表题在表上，数据口径/局限紧接表下。不要把图注写成长正文，也不靠图注承担全部解释。
- 患者截图按原始比例完整嵌入，以留白、细边框和紧邻图注与正文区分，保留原色。信息密集的检查单优先全宽；只有缩放后仍能读清关键字段时才放双栏。超长截图用原图概览交代上下文，再按原顺序放有位置标记的局部图，局部保留项目名、数值、单位及相关参考范围。图注注明原图/局部关系，多图对齐外框与图注，不为等高而拉伸或裁切内容。
- 文献列表采用悬挂编号与适度行距，长 DOI/URL 可换行。让重要医学结论在出现处带编号，文末列完整条目。

预览白底、深色、窄屏和打印；特别检查竖图缩放后的文字、图例与曲线对应关系、参考文献分组，以及图注是否和图片同页。手机上所需字段仍应可读，过密时提供清晰局部图；不以整页无横向溢出代替可读性验收。临床图片保留原色，不随深色模式反色。密集图表宁可拆分为多图，也不要缩到失去科学可读性。
