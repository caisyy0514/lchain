## 来源可信度参考
| 等级 | 类型 |
| --- | --- |
| 高 | 官方网站 / 官方文档 / 政府网站 / 学术论文 / 上市公司公告 |
| 中 | 主流媒体、知名技术社区（如 InfoQ、官方博客） |
| 低 | 个人博客、论坛、问答、自媒体（需其他来源佐证） |
