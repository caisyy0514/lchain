# LChain 问诊智能体（consult） · 产品介绍视频

线性简笔画风格（白底黑线手绘描边 + 少量强调色），**嵌真实界面截图**，165 秒，1920×1080 / 30fps，
带原创背景音乐和中文旁白、字幕。面向要用同一套框架做别的业务的同事：既讲产品，也讲框架怎么复用。

## 技术实现

- `sketch.py`：简笔画引擎（与企微群视频同一套）——3 倍超采样、样条平滑、笔触两头细中间粗、水彩式填色、纸张纹理、文字逐字浮现
- `cprops.py`：问诊专用素材——真实界面嵌图 `ui_shot()`（手绘外框 + 圆角截图）、病历要素清单、闸门、代码卡、目录树、耗时对比条、盖章、文件卡、标签页
- `props.py`：通用素材（人物加了 `coat=True` 的白大褂 + 听诊器）
- `render.py`：多进程逐帧渲染；分镜之间交叉淡化；字幕按旁白实际时间逐句显示
- `music.py` / `voice.py` / `build.sh`：原创配乐 + Edge 神经网络语音 + 混音（旁白时音乐自动压低）
