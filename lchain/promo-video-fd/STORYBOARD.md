# LChain 家庭医生 Agent（VBC 分级诊疗）· 功能介绍视频

线性简笔画风格（白底黑线手绘描边 + 少量强调色），139 秒，1920×1080 / 30fps，
带原创背景音乐和中文旁白、字幕。讲的是 `app/wecom/fd` 这套家庭医生 Agent：
**安全门控 → 多轮问诊 → 分级判定 → 就医计划卡 → 居家观察闭环 → 医生审核**。

成片：`output/fd-intro.mp4`

## 技术实现

- `sketch.py`：简笔画引擎（与企微群 / 问诊视频同一套）——3 倍超采样、样条平滑、笔触两头细中间粗、水彩式填色、纸张纹理、文字逐字浮现
- `props.py`：通用素材（人物 `coat=True` 画白大褂 + 听诊器、手机、气泡、时钟、盾牌、机器人…）
- `cprops.py`：卡片素材（计划卡 `note_card`、目录树 `folder_tree`、闸门 `gate`、印章 `stamp`、勾选项 `check_row`…），`folder_tree` 增加 `title` 参数
- `scenes.py`：10 个分镜的动画 + 时间线 `SCENES`（函数、时长、旁白文案）
- `render.py` / `music.py` / `voice.py` / `build.sh`：逐帧渲染、原创配乐、Edge 神经网络语音、混音（旁白时音乐自动压低，响度标准化 -16 LUFS）

本视频不依赖界面截图（与 `promo-video-consult` 不同），可以直接改 `scenes.py` 重新生成。
